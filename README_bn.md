## ✨ এটা আসলে কী?

**Novel Studio**-এর **সম্প্রসারিত (অ্যাডভান্সড) ভার্সন** — ওয়েবটুন, মাঙ্গা ও ওয়েব নভেলের জন্য একটি **অ-ধ্বংসকারী (non-destructive), সরাসরি-চলমান OCR + অনুবাদ ওভারলে**।

এটি অধ্যায় ডাউনলোড করে না। কোনো সাইটের ডেটাবেস বদলে দেয় না। পাইরেট করা কনটেন্ট হোস্ট করে না।
এটি আপনি ইতিমধ্যেই যে পাতাটি পড়ছেন তার *উপরে* বসে, এবং মূল লেখাটি যেখানে ছিল ঠিক সেখানেই আপনার ভাষায় অনুবাদ এঁকে দেয়।

> **ভাবুন তো, পাতার পেছনে একজন অনুবাদক দাঁড়িয়ে কানে কানে বলে দিচ্ছেন — অথচ পাতা নিজে অপরিবর্তিত।**

## 🧠 "মিডলম্যান" ধারণা

অ্যাপটি আসলে **দুটি ব্রাউজারের মাঝখানে বসা একজন দালাল**।

```
┌──────────────────────────────────────────────────────────────┐
│                        আপনার ফোন                             │
│                                                              │
│   ┌────────────────────────────────────────────────────┐     │
│   │  WebView #১  — আপনি যে পাতা পড়ছেন                  │     │
│   │                                                    │     │
│   │   ┌──────────┐   ┌──────────┐   ┌──────────┐       │     │
│   │   │ প্যানেল ১ │   │ প্যানেল ২ │   │ প্যানেল ৩ │       │     │
│   │   │  漫画の   │   │  テキスト │   │  SFX!!   │       │     │
│   │   │  テキスト │   │          │   │          │       │     │
│   │   └────┬─────┘   └────┬─────┘   └────┬─────┘       │     │
│   └────────┼──────────────┼──────────────┼─────────────┘     │
│            │  পিক্সেল      │              │                   │
│            ▼              ▼              ▼                   │
│   ┌────────────────────────────────────────────────────┐     │
│   │        OCR   →   লেখার বক্স + জ্যামিতি              │     │
│   │        Google Lens  (রিমোট, মূল ইঞ্জিন)             │     │
│   │        ML Kit       (লোকাল, প্রি-ফিল্টার + ফলব্যাক)  │     │
│   └────────────────────┬───────────────────────────────┘     │
│                        │  "এই লাইনটি আছে x, y, w, h-তে"     │
│                        ▼                                     │
│   ┌────────────────────────────────────────────────────┐     │
│   │  WebView #২ — আপনার চ্যাটবট / অনুবাদ প্রোভাইডার     │     │
│   └────────────────────┬───────────────────────────────┘     │
│                        │  অনূদিত লেখা                        │
│                        ▼                                     │
│   ┌────────────────────────────────────────────────────┐     │
│   │   HTML ওভারলে  →  WebView #১-এর উপরেই বসানো হয়      │     │
│   │   〔 これが翻訳です 〕  ← একই বক্স, একই বাবল         │     │
│   └────────────────────────────────────────────────────┘     │
└──────────────────────────────────────────────────────────────┘
```

**উপর থেকে নিচে:** অ্যাপ কমিক পড়ে, অনুবাদককে জিজ্ঞেস করে, আর উত্তরটা ফিরিয়ে পাতার উপরেই লিখে দেয়।

**নিচ থেকে উপরে:** একই সেতু উল্টোদিকেও চলে — চ্যাটবট যা লিখছে, সেটাও পড়া ও বসানো যায়।

### 🔒 অ-ধ্বংসকারী HTML ওভারলে

| চিরাচরিত স্ক্র্যাপার | Novel Studio ওভারলে |
|---|---|
| অধ্যায় ডাউনলোড করে নিজে হোস্ট করে | ❌ কখনোই অধ্যায় নামায় না |
| সাইটের মার্কআপ বদলালেই ভেঙে পড়ে | ✅ লেখা বসাতে সাইটের নিজের DOM ব্যবহার করে |
| ছবি আর মূলের সাথে মেলে না | ✅ একই পাতা, একই স্ক্রল, একই জুম |
| মিরর আর স্টোরেজ লাগে | ✅ ডিস্কে শূন্য কপি |

যেহেতু বসানো হয় **পাতার নিজের HTML ও JS** দিয়ে, তাই অনুবাদটি আর্টওয়ার্কের সাথেই স্ক্রল করে, ভিউপোর্টের সাথে রিসাইজ হয়, এবং মূল বাবলের ভেতরেই বসে — আলাদা কোনো রিডার ভিউতে নয়।

### পুরো অধ্যায় আর পাঁচ মিনিট নেয় না কেন

```
ফেচ (৬ থ্রেড) ───┐
                  ├─► ML Kit প্রি-ফিল্টার (~৪০ মি.সে.) ──► লেখা নেই? Lens বাদ
                  │                                      └─ লেখা আছে? ──► Google Lens
                  └─► Semaphore(৩) ─────────────────────────────► সমান্তরাল উত্তর
```

* **পাইপলাইনিং** — প্যানেল #১ পড়া চলাকালীন প্যানেল #২ ডাউনলোড হচ্ছে।
* **লোকাল প্রি-ফিল্টার** — নীরব আর্ট-প্যানেলে কোনো নেটওয়ার্ক খরচই হয় না।
* **কঠোর রেট লিমিট** — একসাথে তিনটি Lens অনুরোধ, শুরুর মাঝে ২০০ মি.সে. বিরতি। একটা 429 যে সময় নষ্ট করে, সমান্তরালতা তার চেয়ে বেশি লাভ দেয় না।
* **সৎ ব্যর্থতা** — আমাদের কোডের কোনো বাগ পুরো অধ্যায়কে চুপচাপ লোকাল ইঞ্জিনে নামিয়ে দেয় না।

## 🔬 ইঞ্জিন স্ট্যাক

| ভূমিকা | ইঞ্জিন | কেন |
|---|---|---|
| মূল OCR | **Google Lens** | ঘন CJK কলাম আর স্টাইলাইজড লেখায় সবচেয়ে নির্ভুল |
| লোকাল প্রি-ফিল্টার | **ML Kit (অন-ডিভাইস)** | ফ্রি, ~৪০ মি.সে., নেটওয়ার্কে যাওয়ার আগেই বলে "এখানে আদৌ লেখা আছে কি না" |
| ফলব্যাক OCR | **ML Kit (বিস্তারিত)** | Lens ব্যর্থ হলে বা কিছু না পেলে *একই ক্রপে* চলে |
| বাবল জ্যামিতি | **BubbleFit** (পিক্সেল) + ঐচ্ছিক **ONNX ডিটেক্টর** | বাবলের ভেতরটা খুঁজে বের করে, যাতে লেখা শুধু ঢাকা না পড়ে বরং ফিট হয় |
| অনুবাদ | **আপনার চ্যাটবট / প্রোভাইডার** | আপনি আগে থেকেই যে LLM ওয়েব UI ব্যবহার করেন — সেটাই অনুবাদক থাকে |

**চ্যাটবটই অনুবাদ ইঞ্জিন।** অ্যাপটি আপনার দেখানো ওই একই WebView দিয়ে তাকে চালায়, উত্তর পড়ে, নম্বরযুক্ত মার্কার পার্স করে, এবং প্রতিটি উত্তরকে ঠিক যে OCR বক্স থেকে এসেছিল সেখানে ফিরিয়ে বসায়।

## 📖 নভেল মোড

চীনা, কোরিয়ান, জাপানি বা অন্য যেকোনো ভাষার ওয়েব নভেল — নিজের ভাষায় পড়ুন।

* রিডার DOM থেকেই সরাসরি অধ্যায়ের লেখা তুলে নেয় (দ্রুত পথ, OCR লাগে না)।
* শুধু সাইট লেখাকে ছবি হিসেবে রেন্ডার করলে OCR-এ ফিরে যায়।
* একই ওভারলে, একই অনুবাদ প্রোভাইডার, একই গ্লসারি আচরণ।

## 📌 ব্যবহার সম্পর্কে একটি কথা

এটি একটি **ব্যক্তিগত পাঠ-সহায়ক**। এটি কোনো কমিক, মাঙ্গা বা নভেল হোস্ট, মিরর বা বিতরণ করে না। সব কনটেন্ট আপনি যে সাইটে যান সেখানেই থাকে; অ্যাপটি শুধু আপনার ব্রাউজার যা দেখাচ্ছে তার উপরে লেখা বসায়।

আপনি যে সাইটগুলো পড়েন তাদের শর্তাবলি এবং যারা কাজগুলো তৈরি করেন তাঁদের সম্মান করুন।

<div align="center">

**তাদের জন্য বানানো, যারা শুধু গল্পটা বুঝতে চায়।**

⭐ এই প্রজেক্ট যদি আপনার একটা অধ্যায়ের অনুমান-খেলা বাঁচিয়ে দেয়, তবে রিপোতে স্টার দিন।

</div>
